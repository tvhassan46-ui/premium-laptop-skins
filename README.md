# Premium Laptop Skins

مجموعة تصاميم SVG قابلة للتحرير في Adobe Illustrator، بمقاس 1280×800 وقابلة للتكبير بدون فقدان الجودة.

الملفات:
- `cyber-orbit.svg` — تصميم مستقبلي أسود/أزرق/برتقالي
- `black-gold-marble.svg` — تصميم فاخر أسود وذهبي
- `synthwave-mountains.svg` — تصميم Synthwave قوي بالنيون

> قبل الطباعة: قِس غطاء اللابتوب الحقيقي، أضف 3–5 مم bleed من كل جانب، ثم صدّر PDF للطباعة أو PNG بدقة عالية.
